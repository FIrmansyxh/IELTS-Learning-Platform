## 2. Security Assessment
- [x] Pass (tidak ada secret hardcoded, tidak ada injeksi, tidak ada IDOR, tidak ada open redirect yang dapat dieksploitasi)

### Terverifikasi baik
- **IDOR / tenant.** Semua kueri memfilter `user_id = sesi` (`getRadar`, `listBandPredictions`, `listExamHistory`); tidak ada parameter `user_id`; `exam-history` hanya `mode='EXAM'` dan `status IN ('GRADED','EXPIRED')` (Drill tidak muncul), filter `assessment_type` divalidasi enum (`ExamHistoryQuerySchema` strictObject -> `FOO` = 400). Placement: `band_score` dan `passed` selalu null (`service.ts:241,249-250`). `result_path` dibangun server dari UUID attempt (`/ujian/{uuid}/hasil`), bukan dari input.
- **Injeksi SQL.** Daftar `kind` dan `types` dibangun dengan `sql.join(... sql\`${k}\`)` (terparameter), `skill` di-cast `::skill_category`; tidak ada interpolasi string mentah.
- **Pengecualian data tidak sah.** `recomputeAi` memakai `method='AI_LOCAL'` dan `COALESCE(flags->>'injection_suspected','false') <> 'true'` (`service.ts:91-112`); `SELF_ASSESSMENT` dan injeksi tidak pernah dihitung; evaluasi tanpa `flags` dianggap non-injeksi. Objektif: `is_correct IS NOT NULL` (soal AI keluar), `a.status IN ('GRADED','EXPIRED')` (IN_PROGRESS keluar), 50 terbaru (`ORDER BY answered_at DESC, id DESC LIMIT 50`).
- **Atomik dan idempoten.** Hook berjalan dalam transaksi pemicu (kegagalan membatalkan submit/penyimpanan evaluasi). UPSERT `ON CONFLICT (user_id, skill)`, `writeScore(null)` menghapus baris bila sampel nol; hitung ulang pada data sama identik; riwayat `RECALC` hanya bila `x` berubah, `BOSS` idempoten per attempt. `created_at` dibuat monoton (`service.ts:140-142`) sehingga "baris terbaru" tidak ambigu.
- **Deadlock / performa.** Tidak ada kunci advisory baru; pada submit Drill/Boss/Skip hook skill berjalan SESUDAH `gamificationHook` yang memegang `user_stats FOR UPDATE`, sehingga rekomputasi satu pengguna otomatis berurutan. Hook evaluasi (worker) tidak memegang kunci poin dan hanya menulis baris WRITING/SPEAKING (tidak bersilangan dengan baris L/R/G/V); tidak ditemukan siklus penguncian. `getRadar` = 2 kueri PK (sesuai AC <= 3 kueri). Kueri `recomputeObjective` memindai jawaban pengguna per skill (join `attempts` lewat `attempts_user_*`), tumbuh linear terhadap riwayat satu pengguna; wajar untuk skala produk (lihat F-17-12).
- **Tidak ada open redirect yang dapat dieksploitasi.** `result_path` buatan server; FE menyaring lagi (`safeInternalPath`), lihat F-17-07 untuk kelemahan penyaringnya.
- **Radar SVG: aksesibilitas.** Tabel alternatif tersedia (toggle `aria-pressed`, `aria-controls`), `<svg role="img">` + `aria-label` ringkas (terendah/tertinggi), label sumbu 12 px tanpa rotasi, singkatan < 400 px dengan legenda lengkap, titik dapat difokus (area 28 px), tooltip muncul saat hover/fokus/klik dan nilai yang sama ada di tabel, `prefers-reduced-motion` mengganti animasi masuk. Kontras: garis target `--color-secondary-text` (#0f766e / #5eead4), isi `--color-primary` (#4f46e5 / #6366f1 >= 3:1 pada permukaan), teks 12 px `--color-text`/`--color-text-muted` >= 4,5:1.
