### Terverifikasi baik
- **Idempotensi / race poin.** Tiga lapis: (1) `loadLocked ... FOR UPDATE` pada baris attempt menyerialkan submit serentak dan submit ke-2 mengembalikan hasil tersimpan tanpa menjalankan hook (`attempts/service.ts:429-432`); (2) indeks unik parsial `point_ledger_once_uq (user_id, source, source_id)` untuk DRILL/SPEED_STREAK/CROWN/MINI_TASK/BOSS (`drizzle/0010_spec_016_points_unique.sql`, `db/schema.ts:538`) dengan `INSERT ... ON CONFLICT DO NOTHING RETURNING` (`gamification/service.ts:57-66`), dan nilai yang ditambahkan ke `total_points` hanya bila baris benar-benar tertulis (`:101-103, 127-128, 186-193`); (3) `user_stats ... FOR UPDATE` (`lockStats`, `:44-48`) menyerialkan seluruh penulisan poin satu pengguna, sehingga `alreadyAwarded` (G3) selalu melihat penulisan yang sudah ter-commit (READ COMMITTED, pernyataan berikutnya memakai snapshot baru). DAILY tidak memakai indeks unik tetapi dijaga kunci `user_stats` + cabang `last >= today` (`rules.ts:89`).
- **Anti-farming G3.** Poin DRILL dan SPEED_STREAK = `max(0, nilai_baru - SUM(ledger))` untuk attempt-attempt pengguna pada SET yang sama (`service.ts:68-75, 184-185`), jadi PRACTICE berulang pada skor sama = 0 tambahan; total per set dibatasi nilai maksimum set. Mahkota tidak pernah turun (`maxCrown`, `applyCrown` `:141-155`), poin CROWN = selisih nilai (`:186`). Boss: sekali per set Boss lewat `alreadyAwarded(BOSS, set.id)` (`:220-233`) selain `BOSS_ALREADY_PASSED` di gerbang. Mini-Task: `source_id = sub_module_id`, unik per sub-modul; callback hanya dipanggil pada pengisian pertama `mini_task_completed_at` (`player/service.ts:217,235`).
- **Ambang tanpa float.** `crownFromScore`: `rawH*100 >= min*maxH` (`rules.ts:13-18`); 74,99 -> NONE, 89,996 -> SILVER, 90,00 -> GOLD; dibekukan lewat `passed` yang sama dengan keputusan lulus handler.
- **Streak harian tidak dapat dimanipulasi klien.** Hari dihitung dari `nowDate()` server dan `APP_TIMEZONE` (`service.ts:89-96`, `rules.ts:44-65`); tidak ada header/body zona atau waktu yang dibaca (grep `req.headers`/`timezone` di modul gamifikasi nihil). Jam mundur (`last >= today`) tidak mengubah apa pun; `streakView` melaporkan 0 bila terlewat tanpa menulis (G9).
- **Atomik dengan submit.** Seluruh hook dipanggil di dalam `finalize` (`attempts/service.ts:171-172`), di transaksi yang sama dengan skor, `onFinish` Gatekeeping, `runActivityHooks`; pengecualian apa pun membatalkan seluruh submit (tanpa poin/mahkota parsial). Urutan kunci konsisten: attempt -> semua baris progres (`lockProgress`) -> `user_stats`; tidak ditemukan siklus menunggu (aktivitas learn/mini-task mengunci baris progres satu sub-modul lalu `user_stats`; submit mengunci seluruh progres lebih dulu).
- **Append-only ledger.** `REVOKE UPDATE, DELETE ON audit_log, point_ledger FROM app_rw` (`drizzle/0002_custom_views_triggers.sql:42`); kode hanya melakukan INSERT dan SELECT pada `point_ledger` (grep). Tidak ada TRUNCATE yang diberikan. Catatan INFO F-16-08.
- **Tidak ada data pengguna lain.** `GET /me/stats` dan `/me/points` hanya membaca `user_id = sesi`; tidak ada parameter `user_id`; `page_size` maks 50 (`PointsQuerySchema` strictObject) sehingga `page_size=51` -> 400. Kolom `note` hanya memuat kode sub-modul dan hitungan milik sendiri. Cache klien dibersihkan saat logout (`use-auth.ts:30` `qc.clear()`).
- **Klien tidak dapat menyuntik poin.** Endpoint attempt memakai skema strict (SPEC-006); tidak ada rute yang menerima `points`/`crown`; `GamificationBlockSchema` hanya dipakai untuk membaca respons dan di-`safeParse` ulang (blok tak valid disembunyikan, bukan ditambal).
- **Animasi & reduced-motion.** Confetti tidak dirender sama sekali saat `prefers-reduced-motion` (`confetti.tsx`, hook `useReducedMotion` berbasis `useSyncExternalStore`); CSS `@media (prefers-reduced-motion: reduce)` menonaktifkan kilau/confetti dan mengganti animasi mahkota dengan fade; hanya `transform` dan `opacity`. Confetti hanya saat berubah menjadi GOLD (`gamification-result.tsx:26`), 14 keping, 1,2 detik, `aria-hidden`. Mahkota selalu punya `aria-label` teks dan label "Emas"/"Perak" (tidak hanya warna); chip header punya satu `aria-label` ringkas; error memuat stats menyembunyikan chip tanpa Toast sesuai spec.
- **Kontras.** Token teks (`--color-text-muted` #64748b pada putih = 4,76:1; dark #94a3b8 pada #1e293b >5:1) memenuhi 4,5:1. Ikon emas/perak/api (#f59e0b, #94a3b8, #f97316) bukan pembawa informasi tunggal (selalu disertai teks/label), tepi mahkota memakai `*-edge` berkontras >= 4,5:1.
