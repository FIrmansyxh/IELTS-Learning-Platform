### Terverifikasi baik
- **Otorisasi:** semua 10 rute memakai `withApi({ auth: 'admin' })`; mutasi dilindungi CSRF origin check; `POST /import-batches` juga `import_admin` 10/jam per pengguna (`import-batches/route.ts:15`, dikonsumsi sebelum body dibaca). Tes `import.itest.ts:513-533` memastikan learner 403 dan anon 401 pada SELURUH endpoint tanpa efek pada batch. Path `batch_id`/`row_number` divalidasi skema.
- **Unggah/parsing (I2):** batas 5 MB saat streaming (`readMultipart`, `Content-Length` dicek di muka); tipe ditentukan ekstensi nama yang sudah disanitasi DAN `looksBinary` (PK/PDF/MZ/ELF/OLE) -> 415; UTF-8 fatal (`TextDecoder fatal`), BOM ganda, karakter kontrol; `file_name` disanitasi `[A-Za-z0-9._-]` maks 255 dan tidak pernah dipakai sebagai path (berkas disimpan `private/imports/<uuid>` mode 0700 oleh `StorageDriver`).
- **JSON bom / prototype pollution:** `jsonDepth` memindai token SEBELUM `JSON.parse` (aman terhadap bersarang dalam, berhenti saat > 10); `JSON.parse` menghasilkan kunci `__proto__` sebagai properti milik sendiri (tidak mengubah prototipe) dan `hasForbiddenKey` mendeteksinya di kedalaman mana pun lewat `Object.keys` (diuji `({}).x === undefined`); `contract_version` ∈ {1.0, 1.1}; total item <= 2.000. Payload hanya dibaca oleh Zod `strictObject` kontrak SPEC-004 sehingga tidak ada penyalinan properti tak dikenal ke objek.
- **CSV:** `csv-parse/sync` dengan header whitelist (duplikat/tak dikenal/kurang -> `csv_header_invalid`), baris <= 5.000, kolom <= 50, sel <= 5.000; `formula_injection` untuk sel diawali `= @ \t \r` pada SEMUA kolom (`evaluate.ts:235,269-271`); tipe soal CSV dibatasi enam tipe; angka `^\d{1,9}$`; pemisah daftar ` || ` setelah NFC. Tidak ada delimiter/escape injection ke SQL (semua lewat Drizzle).
- **Tanpa SSRF:** `grep` `fetch(`/`http.request`/`axios` di `src/server/import` dan `src/server/content` bersih; `image_url` hanya diterjemahkan ke `asset_code` dari jalur `/storage/...` atau ditolak (`validate.ts:383-391`); tes `import.itest.ts:387` memata-matai `fetch` dengan URL `169.254.169.254`. Video YouTube dibangun dari `video_id` ber-regex (`apply.ts:108`).
- **Atomik/idempoten:** satu transaksi publikasi dengan `lockImports` (advisory 727019) menyerialkan unggah, publish, cancel, rollback; `PublishAbort` melempar di dalam transaksi sehingga `PUBLISH_BLOCKED`/`VALIDATION_CHANGED` tidak menyisakan penulisan (diuji: 0 entitas, 0 revisi). Pengulangan job pg-boss: validasi menimpa item lama (`delete`+`insert`), publikasi di-skip bila bukan `PUBLISHING` (dan job ditutup `SUCCEEDED` bila sudah `PUBLISHED`). Cancel saat berjalan ditangani (`cur?.status !== 'VALIDATING'` return). `DUPLICATE_BATCH` diatur indeks unik parsial `import_batches_file_uq` + cek eksplisit dan hanya untuk status PREVIEW_READY/PUBLISHING/PUBLISHED (sesuai spec; ulang setelah CANCELLED/ROLLED_BACK diterima).
- **Rencana segar:** `runImportPublish` mengevaluasi ulang berkas terhadap DB di dalam transaksi publikasi; galat baru -> `FAILED/VALIDATION_CHANGED`. `set_has_active_attempts` (UPDATE set/drill/CSV dengan `attempts.IN_PROGRESS`) menjadi galat `INVALID` pada validasi dan publikasi.
- **Rollback (I6):** hanya `PUBLISHED`; `CREATE` dihapus hanya bila tanpa `attempts`/`submissions`/progres non-awal/`user_last_learned_state` (satu penahan menolak SELURUH rollback sebelum perubahan apa pun, `rollback.ts:136-169`); `UPDATE` dipulihkan dari snapshot `content_revisions` dengan deteksi `changed_since_batch` dan `snapshot_missing`; urutan hapus set(section) -> set -> sub-modul -> modul; audit `IMPORT_ROLLED_BACK` memuat `actor_user_id` penekan tombol rollback.
- **Retensi (I7):** `purgeImportBatches` menghapus berkas, mengosongkan `payload` (`'null'::jsonb`), mempertahankan hitungan; `getItem` mengembalikan `payload: null` bila purged. Worker mendaftarkan `import-validate`/`import-publish` di luar limiter AI.
- **Render konten impor (XSS):** semua teks soal/opsi/penjelasan/judul dirender sebagai node teks React; artikel lewat `MarkdownArticle` tanpa HTML mentah; kunci jawaban hanya muncul di pratinjau admin (rute admin-only). Tidak ada link dari payload tanpa `safeHref`.

2. (MEDIUM) F-19-02: tambah watchdog/pemulihan untuk batch macet `VALIDATING`/`PUBLISHING` dan izinkan pembatalan saat job tidak berjalan.
3. (LOW) F-19-03: catat aktor publikasi sebenarnya; F-19-04: hindari spread pada array besar; F-19-05: pratinjau payload CSV; F-19-06: kedaluwarsa batch menggantung; F-19-07: kunci baris dan tangani FK saat rollback; F-19-08: tambah tes.
