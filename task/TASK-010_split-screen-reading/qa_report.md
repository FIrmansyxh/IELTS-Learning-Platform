## 2. Security Assessment
- [x] Pass (tidak ada secret hardcoded, tidak ada XSS, tidak ada kebocoran kunci jawaban)

### Terverifikasi baik
- **Rendering `passage_markdown` bebas XSS.** Tidak ada `dangerouslySetInnerHTML`/`innerHTML`/`eval`/`document.write` di `components/reading`, `components/listening`, `components/exam`, `lib/reading` (grep bersih, hanya `next/link` ke konstanta `/peta` dan `/belajar/{kode}`). Teks paragraf dipecah menjadi segmen React (`paragraph-runs.ts` -> `Segment` -> `<span>`/`<mark>` berisi `text.slice()`), sehingga HTML mentah (`<script>`, `<img onerror>`) tampil sebagai TEKS literal. Tautan/gambar Markdown tidak dirender sama sekali (tampil literal), jadi tidak ada vektor `javascript:`. Judul `# ...` masuk lewat `<h2>{passage.title}</h2>` (auto-escape). Sesuai `security-standards.md` 3.2 ("Highlight memakai rentang offset, bukan menyuntikkan HTML").
- **Penyorot: offset vs Markdown konsisten.** Offset disimpan terhadap teks paragraf MENTAH (termasuk penanda `**`/`*`/`- `). `lineRuns` menghitung `start/end` run relatif ke teks mentah dan menaruhnya di `data-start`; `selection.ts` menjumlah `data-start + offset node` sehingga posisi benar walau penanda tidak punya node teks. Seleksi yang melintasi penanda `**` memasukkan penanda ke dalam rentang (tidak merusak). Offset UTF-16 identik dengan `Range` DOM. Tabel/kode dirender `plain` tanpa `data-start` -> tidak dapat disorot (sesuai edge case). Seleksi triple-click (`endOffset=0` pada paragraf berikut) diabaikan dengan benar (`from < to`).
- **`localStorage` berisi data tak tepercaya diperlakukan aman.** `loadHighlights` memakai `JSON.parse` dalam try/catch, `HighlightSchema` Zod per elemen (`int`, `min`), membuang yang `end > panjang paragraf`/`start >= end`, memotong pada 200; `loadFlags` memfilter ke `question_id` yang valid (`exam-runner.tsx`); `loadSplit` di-`clampSplit`; `loadAudioPosition` hanya angka finit >= 0. Nilai yang disimpan hanya pernah masuk ke atribut/teks React (`data-hl-id`, `aria-label`), tidak ke HTML/URL/CSS bebas (warna hanya `enum`). Tidak ada prototype pollution (indeks numerik pada array). Isi tersimpan tidak mengandung PII (hanya angka offset, uuid attempt, uuid soal).
- **Tidak ada kebocoran kunci jawaban di mode ujian.** Soal publik lewat allow-list `toPublicQuestion`; `ExamSession`/`QuestionGroupList` selalu `feedback={null}`; `answers[].feedback` hanya diisi bila `mode==='PRACTICE'` (`dto.ts:71`); `questions` kosong setelah selesai; hasil EXAM Skip/Boss/Placement tidak memuat `is_correct` per soal (`HIDE_REVIEW_TYPES`, tindak lanjut F-08-01). `passage_markdown` bukan kunci (spec 010) dan tidak memuat jawaban dari server. `reading.itest.ts` menguji "tanpa kunci jawaban di soal publik".
- **Kepatuhan alur simpan/waktu:** PUT answers dengan debounce 400 ms, backoff 2/4/8 detik, `finish()` menolak submit bila ada simpan gagal (kecuali waktu habis), `beforeunload` kini ada (menutup F-08-09c), jam server disinkronkan 60 detik tanpa menyentuh jawaban lokal; deadline otoritatif di server. Kunci rate limit dan CSRF tidak berubah.

### Temuan keamanan
Tidak ada CRITICAL/HIGH. Risiko privasi kecil pada `localStorage` (F-10-03) dan integritas data sorotan (F-10-02).
