### Terverifikasi baik
- **Otorisasi:** seluruh 12 handler memakai `withApi({ auth: 'admin' })` (`requireUser(..., requireAdmin)`), termasuk `GET /admin/assets/{id}/file`; mutasi diberi CSRF origin check (`withApi.ts:74-86`). `learner` 403 dan tanpa sesi 401 diuji (`assets.itest.ts:220,372,394`). Tidak ada IDOR (sumber daya admin global).
- **Path traversal / nama berkas:** nama berkas klien tidak pernah dipakai. `FsStorageDriver.put` membangun key `<dir>/<uuid>.<ext>` dengan `dir` dari allow-list dan `ext` dari hasil deteksi server; `resolve` memeriksa `validKey` (regex UUID + shard/dir whitelist) lalu `startsWith(root + sep)` (`storage/index.ts:20-38`), `writeFile` flag `wx`, berkas parsial dihapus saat ENOSPC. `asset_code` hanya kolom DB, regex `^[a-z0-9][a-z0-9/_-]{2,79}$` tidak mengizinkan titik sehingga `..` mustahil. Direktori `private/imports` mode 0700; `ASSETS_DIR` default di luar `public/` Next.
- **Magic bytes / ukuran:** MIME = hasil `file-type` (ekstensi/Content-Type klien diabaikan, `validateAssetBytes` `content/assets.ts:217-231`); SVG/EXE -> `unsupported_file_type` -> 415. Ukuran ditegakkan saat membaca aliran (`multipart.ts:43-61`: batas `kind` + 64 KB slack, `reader.cancel()` saat lewat batas, `Content-Length` dicek di muka); urutan field FE (`kind` sebelum `file`, `lib/api/assets.ts:54-60`) membuat batas per-kind aktif dini; pemeriksaan akhir `uploadLimitBytes` di service (`registry.ts:227`).
- **Gambar:** re-encode `sharp` membuang EXIF/GPS (diuji); `limitInputPixels` ada. **DOCX:** `vbaProject.bin` ditolak, struktur ZIP minimal diperiksa. **Audio:** `ffprobe` dipanggil lewat `spawn` dengan argumen array (tanpa shell), jalur sementara tetap `in.<ext>` di `mkdtemp`; durasi wajib terbaca (`strictAudio`).
- **Dedup/atomik:** `sha256` dihitung pada byte akhir (setelah re-encode), indeks unik menutup balapan; berkas dihapus bila transaksi gagal (`registry.ts:282-293`). Video: advisory lock per `external_ref` (`registry.ts:332`).
- **SSRF:** tidak ada fetch server-side di seluruh modul (grep `fetch(`/`http.request` bersih). URL eksternal hanya diurai (`new URL`), skema `https:` dipaksa Zod (`httpsUrl`), userinfo ditolak, host video di-allow-list, `external_ref` harus sama dengan id video hasil parsing URL.
- **Penegakan lisensi:** (a) sumber `LINK_ONLY_COPYRIGHTED`/`EMBED_TOS` tidak dapat `may_store_copy=true` (Zod `superRefine` + `updateSource` + CHECK DB); unggah ke sumber `may_store_copy=false` -> 409 `SOURCE_NOT_STORABLE` sebelum satu byte pun diproses (`registry.ts:209-215,229`); aset eksternal `storage_key=NULL` (CHECK `location_chk`). Jadi `LINK_ONLY_COPYRIGHTED` tidak dapat menyimpan salinan lewat jalur unggah maupun impor (`validate.ts:348,501`). (b) status awal selalu `UNVERIFIED` (video) / `LINK_ONLY` (rujukan); verifikasi hanya via PATCH admin dengan matriks per `kind`, kesesuaian sumber (`OWN_ORIGINAL` hanya sumber `OWN`; `VERIFIED_OPEN` hanya CC0/CC_BY/CC_BY_SA/CC_BY_NC/MIT), atribusi wajib untuk CC_BY*/share-alike, dan `ASSET_IN_PUBLISHED_USE` (`registry.ts:419-441`). (c) `UNVERIFIED` memblokir publikasi lewat `v_publish_blockers` yang dipakai `PublishService` (`publish.ts:28-47`) untuk bahan ajar dan `listening_asset_id`.
- **SQL injection:** semua kueri Drizzle terparameter; `ILIKE ... ESCAPE '\'` dengan `escapeLike` (`registry.ts:373-383`); `sql` literal hanya menerima id yang sudah divalidasi `Uuid` oleh `AssetIdParamSchema`.
- **Penyajian berkas admin:** `Content-Type` dari DB, `nosniff`, `private, no-store`, `attachment` untuk dokumen, `Range` audio tervalidasi (`parseRange` menolak `NaN`/di luar ukuran; `registry.ts:484-528`).
- **Audit:** `SOURCE_CREATED/UPDATED`, `ASSET_UPLOADED`, `ASSET_EXTERNAL_CREATED`, `LICENSE_STATUS_CHANGED` (`asset_id`, `from`, `to`), `ASSET_DELETED` ditulis dalam transaksi yang sama dengan mutasi, dengan `actor_user_id` dan `ip_hash`.
